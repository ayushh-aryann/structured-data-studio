Learning outcomes

In plain language, this course develops the following abilities.

  1. Explain transaction processing, concurrency control and database recovery.
  2. Build distributed and object-oriented databases and apply concurrency and recovery algorithms.
  3. Implement distributed and object-oriented DBMS for information processing and storage.

Syllabus overview

Transactions and recovery

Transaction scheduling, concurrency control, recovery methods, caching and backup architecture.

Distributed databases

Fragmentation, replication, distributed updates, reliability and transaction management.

Object-oriented databases

Object persistence, object-relational features, nested tables and database migration.
