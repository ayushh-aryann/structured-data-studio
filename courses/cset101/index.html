Learning outcomes

In plain language, this course develops the following abilities.

  1. Solve problems in Python using standard programming constructs.
  2. Build programs using object-oriented language features.
  3. Use Python APIs to write functions.

Syllabus overview

Python foundations

Applications of Python, number systems, variables, data types, operators, conditional statements, lists and tuples.

Iteration and functions

Loops, list comprehensions, function arguments, recursion, dictionaries and sets.

Files and object-oriented programming

Strings, file handling, exceptions, modules, classes, inheritance and interactive graphics.
