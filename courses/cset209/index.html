Learning outcomes

In plain language, this course develops the following abilities.

  1. Explain operating system structure and services.
  2. Explain scheduling, deadlocks, memory management, synchronisation, system calls and file systems.
  3. Examine distributed operating systems, cloud computing and virtualisation.

Syllabus overview

Processes and CPU scheduling

Operating system architecture, process states, system calls, threads and scheduling algorithms.

Memory and storage

Paging, segmentation, virtual memory, page replacement, file allocation and disk scheduling.

Distributed systems and security

Remote procedure calls, distributed file systems, consistency, authentication and access control.
